Política de Privacidade

Última atualização: 05/10/2026

1. Dados utilizados

O YaguinnFPS Bot utiliza apenas as informações necessárias para fornecer suas funcionalidades dentro do Discord. Para o Editor Universal de Embeds, o bot poderá processar identificadores técnicos fornecidos pelo Discord, como ID do servidor, ID do canal e ID da mensagem, além do conteúdo fornecido voluntariamente por um administrador ao utilizar os comandos do bot.

2. Armazenamento

O bot poderá manter localmente referências necessárias para gerenciar os embeds criados, incluindo IDs de mensagens e canais. Esses dados são utilizados para permitir funcionalidades como editar, duplicar ou excluir embeds posteriormente.

3. Dados sensíveis e financeiros

O YaguinnFPS Bot não foi desenvolvido para coletar senhas, credenciais de acesso ou informações financeiras dos usuários.

4. Compartilhamento

Os dados utilizados pelo bot não são vendidos. O conteúdo fornecido ao bot poderá ser transmitido ao Discord quando necessário para publicar ou modificar um embed solicitado pelo próprio usuário.

5. Retenção e exclusão

Os dados são mantidos somente enquanto necessários ao funcionamento das funcionalidades correspondentes. Solicitações relacionadas à exclusão de dados associados ao bot podem ser realizadas através do contato informado abaixo.

6. Discord

A utilização do aplicativo também está sujeita às políticas e práticas de privacidade do próprio Discord.

7. Contato

Para questões de privacidade ou solicitações de exclusão de dados, entre em contato pelo Discord: @yaguinnfps.
